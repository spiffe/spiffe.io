SPIFFE specifications define the identity model and the interfaces implementations use. Each document below is readable here, with a link to its canonical source and the upstream stability designation.

Start with **SPIFFE ID**, then **X.509-SVID** or **JWT-SVID**. Read the **Workload API** to obtain credentials and **Federation** to verify identities across trust domains.

<SpecExplorer />

The specifications share a [stability policy](/docs/spiffe/specs/stability/). An individual section can have a different stability level from its parent document; the markers in the document apply.

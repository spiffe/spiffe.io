Before an upgrade, read the [version-specific migration instructions](/docs/spire/maintenance/upgrading/), back up the datastore, and plan the server and agent rollout together. Check credential issuance and rotation during the rollout.

For routine operation, monitor [telemetry](/docs/spire/deploying/telemetry_config/) and review [availability and scaling](/docs/spire/planning/scaling_spire/). Chart deployments have their own [upgrade procedure](/docs/spire/helm/upgrading/).

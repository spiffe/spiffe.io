Begin by choosing your trust domains, the nodes that will run agents, and the runtime attributes that distinguish workloads. Select node and workload attestors that match those environments.

Start with [scaling and availability](/docs/spire/planning/scaling_spire/). Use [federation](/docs/spire/architecture/federation/) to connect separate trust domains, or [nested servers](/docs/spire/architecture/nested/) to distribute issuance within one domain. [Extend SPIRE](/docs/spire/planning/extending/) when your platform needs a custom plugin.

Next, [configure and deploy the server and agents](/docs/spire/deploying/).

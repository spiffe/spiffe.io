SPIRE is a production-ready implementation of SPIFFE. Its server manages identity policy and issuing authorities; agents attest nodes and workloads, deliver SVIDs, and keep credentials current.

## Start here

1. [Understand attestation and issuance](/docs/spire/about/concepts/).
2. [Run a local server and agent](/docs/spire/try/getting-started-linux-macos-x/) and retrieve your first SVID, or use the [Helm quickstart for Kubernetes](/docs/spire/helm/installation/#quick-start).
3. [Plan the deployment](/docs/spire/planning/) before choosing attestors, storage, and availability requirements.
4. [Configure SPIRE and register workloads](/docs/spire/deploying/).

For an existing installation, start with [operations and upgrades](/docs/spire/maintenance/).

SPIFFE identities can be issued by a wide range of platforms, from open source projects like SPIRE to commercial and managed cloud offerings. Once a workload has an identity, it can use it across a growing list of software: cloud and AI APIs, identity providers, secrets managers, service meshes, data platforms and CI/CD tools all accept SPIFFE identities, and SDKs and helpers fill the gaps.

Because they all build on the same standard, a workload can use one short-lived, automatically rotated identity to authenticate to each of them, in place of a long-lived API key or password per service.
